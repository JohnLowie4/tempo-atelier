# Tempo Atelier (In progress)

Updated 2026 July 28

## The Problem

Many modern metronome apps on the iPhone only have a BPM selector or dial for the user to select the tempo when they practice their instrument. This is a very common availability for modern musicians and music.

Unfortunately, there are many older music that still use the Italian tempo for their pieces that don't normally include the BPM for musicians to practice with.

Some musicians have memorized these Italian tempo, while others have to google the general tempo for these words before setting the metronome for practice.

## The Solution

Tempo Atelier seeks to bridge this gap between searching for the right tempo and practicing efficiently.
